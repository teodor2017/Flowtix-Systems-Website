Flowtix IT Agent

In production at clients
Built with

.NET, Microsoft Teams, Claude, Freshservice, SharePoint, Confluence, Azure

An AI IT-support agent wired into ticketing. Employees ask in Microsoft Teams, by phone or by email. The agent answers from their company's own documentation and opens or enriches tickets in Freshservice, so engineers get fewer, better tickets.

What it does

  • Answers in Teams, in personal and team chats, with files. One app serves every client company.
  • Picks up the phone: a number per client, the caller speaks, the agent answers from the same knowledge.
  • Reads each client's docs synced from Confluence and SharePoint. End-user and engineer docs are kept apart.
  • Opens tickets from chat and from per-client request forms, and sends self-help tips on email tickets.
  • Leaves engineers a private note with likely fixes on every new ticket.
  • Finds documentation gaps: groups tickets by missing topic and drafts the article for engineers to review.

You stay in control

  • Access is matched strictly by client email domain. Each company sees only its own docs and forms.
  • Low-confidence answers go to engineers for review, not to the user.
  • Dashboard with chat logs by company, user and period, tickets, feedback and call logs, with admin roles.

Flowtix Traffic

Field pilot completed in Brașov
Built with

.NET 8, Docker, live navigation data, OpenStreetMap, GTFS-Realtime, MQTT, DATEX II

Smarter green lights from live navigation data. A software layer over any intersection, with no new sensors in the road. The product Flowtix started with.

Results from the Brașov pilot

IndicatorBeforeAfterChange
Average waiting time37 s25.5 s−31%
Peak waiting time101 s66.5 s−34%
Traffic imbalance between approaches46%27%−41%
Peak travel time through the intersection229 s194.5 s−15%
Average travel time through the intersection165 s153.5 s−7%

One intersection (Strada Lungă × Nicolae Iorga), three weekdays compared before and after the optimized signal plans went live. Real traffic, in sun, rain and light snow. Waiting time dropped on every test day: −36%, −23%, −37%.

What it does

  • Measures delay on every approach from live traffic data, including streets with no signals.
  • Recalculates cycle, green splits and green-wave offsets, with public transport priority.
  • Detects incidents against history, looks for the cause and suggests actions for dispatch, local police and city hall.
  • Smart-city modules: air quality, variable message signs, parking guidance, DATEX II export.

You stay in control

  • Predictions are scored against reality every day, and the accuracy is shown.
  • Control goes from recommendation, to operator approval, to autonomous, with safety limits, rollback and an emergency stop.
  • Runs on-premises, with a daily cost cap on traffic data and an audit trail for every command.
